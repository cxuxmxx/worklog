# Worklog

업무 중 습득한 지식과 개발 과정에서 얻은 경험을 기록하는 저장소입니다.

개념을 이해하는 데서 그치지 않고, 실제로 마주한 문제와 해결 과정, 설계 시 고려한 선택과 이유를 함께 정리합니다.

## 기록하는 내용

- 컴퓨터 과학과 소프트웨어 개발의 기초 개념
- 언어·프레임워크의 동작 원리와 활용 방법
- 시스템 설계와 기술적 의사결정
- 운영 중 발생한 문제의 원인 분석과 해결 과정
- 업무 개선 과정에서 얻은 배움과 회고

## 기록 원칙

- 배경과 문제, 해결 과정, 배운 점을 중심으로 작성합니다.
- 확인된 사실과 가정·의견을 구분하고 참고 자료를 남깁니다.
- 새로운 경험과 검증 결과에 따라 내용을 보완합니다.
- 회사·고객의 민감한 정보와 인증 정보는 포함하지 않습니다.
